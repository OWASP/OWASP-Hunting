# Code of Conduct

OWASP Hunting is an OWASP project and follows the [OWASP Code of Conduct](https://owasp.org/www-policy/operational/code-of-conduct). It applies to everyone taking part in the project: in issues, pull requests, discussions and any other project space.

To report a concern, contact the project leader at [stalin.s@owasp.org](mailto:stalin.s@owasp.org), or OWASP through the reporting options in the Code of Conduct.

The project also expects payloads and techniques to be used only for authorized testing, as described in [DISCLAIMER.md](./DISCLAIMER.md).
