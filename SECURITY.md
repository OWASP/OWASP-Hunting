## Security

If you discover a security vulnerability, please report it responsibly to [stalin.s@owasp.org](mailto:stalin.s@owasp.org). For encrypted reports, use our OpenPGP public key: https://keys.openpgp.org/vks/v1/by-fingerprint/AFC6CF9A21482A23C7C590AC480BC248ABC54AEA

### What to report here

Report vulnerabilities in the project itself: the GitHub Actions workflows, the scripts under `scripts/`, and the documentation website. Please do not open a public issue for these.

The payloads in this repository are intentionally offensive test strings for authorized security testing. A payload that works as intended is not a vulnerability in this project. Problems with payload content, such as a wrong or broken payload, can be reported as a regular issue.
